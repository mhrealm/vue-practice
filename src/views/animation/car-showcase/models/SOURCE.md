# Porsche 911 Model

- Original model: ["Porsche 911 Carrera 4S"](https://sketchfab.com/3d-models/free-porsche-911-carrera-4s-d01b254483794de3819786d93e0e1ebf)
- Author: [Karol Miklas](https://sketchfab.com/karolmiklas)
- License: [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Source used here: https://github.com/esc5221/drive-game/blob/main/public/models/911.glb

The source model was Draco-compressed. It has been converted once with `gltf-transform copy` to `porsche-911.glb`, so the Vue demo can load it with plain `GLTFLoader` and does not require `DRACOLoader` at runtime.
